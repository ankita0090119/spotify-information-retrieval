# spotify-information-retrieval
Implemented TF-IDF, BM25, and content-based filtering  on 114,000 Spotify tracks. Built a working song search  system and recommendation engine from scratch.

## Tech used
Python, scikit-learn, rank-bm25, pandas, Google Colab

## Dataset
Spotify Tracks Dataset (Kaggle) — 114,000 songs, 125 genres
